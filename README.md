# LinuxLab — интерактивная PWA для обучения Ubuntu

Полностью автономный, статический тренажёр для системного администратора, на русском языке.

## Что включено

- **14 учебных модулей** с короткой теорией и примерами.
- **151 упражнение** с ручным вводом команд и проверкой без выполнения.
- **16 смоделированных инцидентов** со стадиями расследования и терминальным выводом: systemd, Nginx, DNS, SSH, TCP, диск, inode, OOM, Docker, TLS и т. п.
- **4 уровня**: новичок, базовый, продвинутый, эксперт. В фильтре кейсов три уровня.
- Интервальное повторение 1 / 3 / 7 / 14 / 30 / 60 дней, поиск слабых мест, экзамен.
- 73 записи в справочнике, XP, дневная цель, график активности, локальное сохранение, экспорт и импорт прогресса.
- Service Worker и web manifest: после первой загрузки под HTTPS можно работать офлайн.

## Запуск локально на Mac / Windows / Linux

Распакуйте ZIP, откройте терминал в папке `linux-lab-pwa`:

```bash
python3 -m http.server 8000
```

В браузере на компьютере откройте `http://localhost:8000`. Можно использовать `npx serve .` или VS Code Live Server. Прямое открытие `index.html` через `file://` не позволит установить PWA и включить Service Worker.

## Установка на iPhone (бесплатно)

PWA необходимо разместить на **HTTPS**. Два варианта:

### Вариант A — GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него файлы из папки приложения (без дополнительной вложенной директории).
2. В Settings → Pages → Build and deployment выберите **Deploy from a branch** → `main` и `/ (root)`, сохраните.
3. Откройте полученную HTTPS-ссылку в Safari на iPhone.
4. Нажмите кнопку «Поделиться» → «На экран Домой» → «Добавить». Выбирайте открытие как веб-приложения, если iOS предложит этот вариант.
5. Запустите LinuxLab с рабочего стола. После полной загрузки оно умеет работать без интернета.

### Вариант B — Cloudflare Pages

1. Создайте проект Pages с загрузкой статических файлов (Direct Upload).
2. Загрузите содержимое папки приложения или ZIP проекта в Cloudflare Pages (в зависимости от интерфейса загрузки).
3. Откройте выданную HTTPS-ссылку с iPhone и добавьте на экран «Домой» через Safari.

Необязательно покупать домен или Apple Developer account.

## Обновления

Файлы можно заменять и перевыкладывать. При изменении `sw.js` измените `CACHE_NAME`, например `linuxlab-static-v1.3`, чтобы браузер увидел новую версию офлайн-кэша. Прогресс будет храниться отдельно в localStorage по origin: **если адрес сайта изменится, перенесите прогресс через Настройки → Экспорт/Импорт**.

## Техническое устройство

- `index.html` — оболочка.
- `styles.css` — адаптивный интерфейс.
- `content.js` — модули, вопросы, сценарии.
- `app.js` — тренажёр, маршруты, проверка, прогресс, повторения.
- `sw.js` — офлайн-кэш.
- `manifest.webmanifest`, `icons/` — установка на домашний экран.

Никакой сборки и npm-зависимостей нет: чистые HTML, CSS и JavaScript.

## Важные ограничения версии 1

- **Это симулятор, а не терминал Ubuntu**: произвольные Linux-команды не исполняются. Сценарии ожидают определённые диагностические шаги. Альтернативные валидные варианты могут не распознаваться — проверку можно расширить.
- Проверка команд не является полноценным shell-парсером. Некоторые варианты написания флагов и синонимы могут потребовать добавления в `content.js`.
- Прогресс хранится в браузере локально и может потеряться при очистке данных сайта. Делайте резервные копии.
- Для синхронизации между устройствами, живого терминала, AI-оценивания и генерации бесконечных кейсов потребуются backend и модель или песочница. Реальные команды на прод-серверах никогда не стоит выполнять без явного разрешения и изоляции.
- В экзамене ошибки валидации учитываются как неправильный ответ; это отличный режим для закрепления точного синтаксиса, но не сертификация.
